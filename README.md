## 📖 Sobre o Projeto

O **Sistema de Alerta Inteligente** é uma solução tecnológica de baixo custo que une o melhor do **desenvolvimento web**, **automação embarcada** e **aplicações mobile** para criar uma ponte direta entre quem precisa de ajuda e quem pode ajudar.

Em situações de emergência, cada segundo conta. Ao pressionar um botão físico conectado ao **Arduino**, um sinal é enviado instantaneamente via **Bluetooth** para o painel de monitoramento, acionando um **buzzer** e um **LED** de alerta. O sistema notifica a sala dos monitores em tempo real, garantindo uma resposta rápida e eficiente.

---

## 🎯 Objetivos

- **Agilidade:** Reduzir o tempo entre o pedido de ajuda e a ciência do monitor para menos de 2 segundos.
- **Acessibilidade:** Permitir que qualquer pessoa acione o alerta, mesmo com dificuldades motoras.
- **Segurança:** Garantir que o alerta não passe despercebido, com sinal sonoro e visual.
- **Baixo Custo:** Utilizar tecnologias de código aberto e hardware acessível (Arduino).
